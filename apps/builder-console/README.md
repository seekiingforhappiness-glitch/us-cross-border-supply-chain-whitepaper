# 建造者透视镜 v1（Builder Console）

> 把系统的内在设计，摊开给建造者看。
> 给创始人 Daniel 的独立可视化应用——**零后端**、只读、暗色蓝图风。
> 依据：`docs/control-tower-plan-v0.2.md` 的 V4 决议（产品形态重构·建造者透视镜）。

这不是又一个数据看板。它遵守一条铁律：**每个视图回答一个问题**，拒绝把 34 个对象直接画成节点连线图（上一版被判「没有意义」）。审美锚点是 Palantir Ontology 的等距分层图：具象、分层、立体、重点突出。术语一律配白话。

---

## 一条龙启动（三步）

```bash
# 0) 进目录
cd apps/builder-console

# 1) 生成数据快照（只读读取 ontology JSON + data/ontology.sqlite，写出 src/data/*.json）
python3 export_data.py
#    需要仓库根的 data/ontology.sqlite 存在；脚本只 SELECT，绝不写库。

# 2) 装前端依赖（仅首次）
npm install

# 3) 起开发服务器
npm run dev
#    打开终端里打印的 http://localhost:5173
```

生产构建与本地预览：

```bash
npm run build     # tsc 类型检查 + vite 打包到 dist/
npm run preview   # 本地静态预览 dist（http://localhost:4173）
```

> **为什么必须先跑第 1 步**：`src/data/*.json` 是导出脚本的产物，被仓库根 `.gitignore` 的 `data/` 规则忽略（生成物不进版本库）。没跑导出，前端会 import 不到数据、构建失败。数据变了就重跑 `export_data.py`。

## 等距图怎么实现的

- **纯手写**，不引入任何图表库。三层平面用等距投影 `project(x,y,z)=(cx+(x-y)·UX, base+(x+y)·UY−z)`（2:1 dimetric）在 SVG 里直绘菱形平面 + 蓝图网格线 + 层间连线。
- **SVG + HTML 混合**：等距地板、底座菱形节点、连线用 SVG（`preserveAspectRatio` + 与 viewBox 同比例的容器，无信箱黑边）；元素卡片用绝对定位的 HTML（中文清晰、可悬停），坐标由同一投影换算成百分比。
- 三层 z 间距 ≥ 平面纵深，做成 exploded-axonometric（爆炸分层），层与层不互相穿插。悬停某元素时，只高亮它的接入/兜底连线，其余淡出——「重点突出」。

## 诚实口径（重要）

- **数字全部实时取自快照**，不写死统计数字（全局规则 5）。宪法条文等稳定文本作者写、数字机器取，两者分离。
- 两张表当前为空，如实呈现、不伪造：`resolution_memory=0`（先例尚未回填）、`llm_calls=0`（LLM 遥测尚未接入）。视图四/五/六据此标注「待回填 / 快照为空」，并解释飞轮第一环尚未接通。这是真实进度，不是演示态。
- 页面处处标注**数据截至时间**与 `READ-ONLY`；底部状态条常驻快照透明度。

## 硬约束（已遵守）

- **只读一切**：`export_data.py` 以 `mode=ro` 打开 sqlite，只 `SELECT`/`PRAGMA`。
- **零后端**：构建期消费静态 JSON，产物是纯静态站点，可挂任意静态托管。
- **不改任何现有代码**：本任务只新增 `apps/builder-console/`。
- **脱敏**：导出只含 ID、业务数字、状态、里程碑事件；不导出个人信息类字段。

## 目录

```
apps/builder-console/
├── export_data.py          # 只读导出脚本（读 ontology JSON + sqlite 三表 + 运行账本）
├── src/
│   ├── data/*.json         # 导出产物（gitignore；构建时消费）
│   ├── components/         # 等距场景 / Tooltip / 图标 / 视图头
│   ├── views/              # 六个视图
│   ├── types.ts            # 与导出脚本一一对应的数据契约
│   ├── styles.css          # 设计系统（蓝图暗色）
│   └── views.css           # 视图专属样式
└── index.html
```

## 技术栈

React 18 + Vite 5 + TypeScript。可视化纯手写 SVG/CSS，无重型图表库。中文界面，术语带白话。
