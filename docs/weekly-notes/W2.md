## 架构决策（本周落定）

1. **干净世界 + emit 层污染**：先生成真实世界，噪声只污染源表导出；oracle 读干净世界，
   W4 引擎读含噪源表——评估测的正是"从噪声中重建真相"的能力（D6 的落地形态）。
2. **规则澄清**（已同步 manual §7 / JSON）：R1/R2 跳过 delivered；R2 跳过已放行；
   事件 severity = 行级取最大。
3. **JIT 排船**：分配选 ETA 最贴近承诺日的船，延误才会真实击穿（原实现余量过大，击穿稀少）。
4. **多客户击穿确定性补齐**：plan §9 要求"人为设计 ≥15"，靠随机涌现不可靠，
   实现 `ensure_multi_customer_breach` 确定性 pass。
5. **customs_hold**：文件缺失的船到港后进入海关扣留，不再静默放行。
