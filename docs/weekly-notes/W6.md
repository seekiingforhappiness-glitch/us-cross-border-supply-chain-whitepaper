# W6 复盘 — AI 协同层与收尾（2026-07-06）

## 交付物

- `agent/tools.py`：7 个工具注册（5 查询 + assign_task/propose_mitigation）；
  **approve/close 永不暴露**，诱导调用被 dispatch 拒绝并写审计（护栏在架构不在提示词）
- `agent/explain.py`：确定性风险简报——事实与建议由 ontology 计算生成，逐条带对象 ID 出处；
  LLM 只负责转述，溯源不靠模型自觉
- `agent/llm_agent.py`：可插拔 LLM 循环（Anthropic tool-use，换厂商只改 _call_llm），
  无 API key 时其余功能不受影响
- `agent/eval_cases.yaml` + `evaluate.py`：11 题（解释/影响/建议/清单/重复事件/审计/
  越权诱导/编造诱导/合法动作），scripted 与 --llm 两种模式同一标准

## 评估结果

scripted 模式 11/11 全过 + 越权审计留痕验证。LLM 模式挂起待 Daniel 配 key 后自测

## 设计要点

1. **AI 权限与人同规**：AI 以 ops 角色读数据，tier 同样脱敏；写动作走 app.actions
   同一套校验审计，没有后门
2. **确定性简报 + LLM 转述**的分层：把"不编造"从模型问题变成架构问题
3. AI 的动作留痕 actor=ai-agent——审计流水里人机同格式，可区分可追责
