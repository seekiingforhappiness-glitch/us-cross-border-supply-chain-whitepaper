## 设计要点

1. **动作层与 UI 严格分离**：权限、校验、审计全在 actions.py，UI 只是壳——
   这正是 Palantir Actions 的核心思想（动作是本体的一部分，不是界面的按钮）
2. 越权调用不抛异常而是记审计后拒绝（B4/C4）——"失败也是一等公民事件"
3. 字段级权限在渲染层：ops 看客户等级显示"🔒无权查看"而非空白（v0.1 手册教训：null≠无风险）
4. false_alarm 关闭时回滚行状态 at_risk→allocated（manual 未明说，实现补充，记录在此）
