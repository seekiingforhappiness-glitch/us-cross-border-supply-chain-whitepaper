## 三、轮2 新发现（高置信，按严重度）

**P1（本轮修复批）**
1. 提案队列金额列无口径（=处置成本），与影响面板货值合计并存无标注 → 列头+面板双侧标口径
2. WorkQueue 行键盘不可达（tabIndex=-1/无 role/无 onKey），覆盖全部下钻队列（复测+两陌生人）
3. RiskEvent 详情卡「处置状态：未处置」在提案/任务在途时自相矛盾（李珊/陈会计独立发现）——
   业务上"任务完成≠风险关闭（等 ops 确认）"正确，但 UI 不解释 → 详情卡补处置链路派生提示
4. runtime 派单失败报错含内部代号「（单风险单任务，D9/C4）」直接暴露业务用户（李珊/陈会计）
   → 人话化+补"打开已有任务"动线
5. 协作流 tab 纯只读且卡片不可点（李珊任务3 完全失败）——催办动作接线涉治理面候裁，
   本轮先做：卡片可点开关联风险/任务 + 诚实导流文案（操作去 Streamlit 操作台）
6. 对话框开着切角色，ObjectCard 权限提示不刷新（陈会计实测"明明切了经理还说不能批"）→ 核实修复
7. React key 冲突：CustomersCtx 用脱敏占位符"🔒无权查看"当列表 key（控制台 8 次告警，ops 角色）

**P2（本轮顺手/下轮）**
8. 「确定性剧本 vs 真模型」标识藏在 run 时间线深处（王总；涉不变量 11 标注义务）→ feed 卡面标 mode
9. 备选方案代价表两格全空仍摆表（王总）→ 空态改一句话
10. 现金水位预警（14 天净流出击穿阈值）藏钱区下钻底部（陈会计"最要命的信号藏最深"）→ 钱卡副行上浮
11. 履约区 EMPTY_HINT 指路「航线视图」但航线图无逐票列表（李珊）→ 文案如实改
12. 放权阶梯导流跳转不锚定目标版块（复测）
13. 「完整血缘见透视镜」悬空引用+分派策略版本号 demo-ops-seed-v1 暴露（陈会计）→ 文案收敛
