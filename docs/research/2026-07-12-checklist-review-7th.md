## 值得进 v2.2 增补（5 条，规格级一两句话，不动已裁决事项）

1. **S1 提示词注入纪律+晋升前置条件**：两份规格的结构性缓解很强（确认队列+提案制+预审模板三道人闸），但**从未把"提示词注入"命名为威胁**——外部原文只作数据段传入、输出过 schema 校验、含指令样文本进毒信队列；**关键连锁：一旦某解析类型晋升"自动确认"，人闸消失、注入缓解归零——注入对抗用例过评估集必须列为晋升前置条件。**
2. **D4 上下文预算与"绝不静默截断"**：只有成本预算没有输入量预算，而本项目输入天然无界（长邮件串/大 CSV/增长的先例上下文）。每类 LLM 调用定输入 token 上限，超限=分块或进毒信队列，绝不静默截断（来源文档："静默截断必需字段是生产管线静默失败的头号来源"）。
3. **H2 待批提案超时语义**：提案 24h 未批自动**过期并按最新世界快照重算再报**（默认通过违宪法⑤，默认搁置会让人批准一个过时世界上的提案）。
4. **F2 claude_cli 故障回退一行规则**：主力是订阅通道（限流/中断概率高于 API）——连续失败 N 次自动进降级模式并告警；切换 provider 须人批。
5. **O1+O3 llm_calls 结构化日志表**：trace_id/provider/模型/token/耗时/成本/状态，所有通道必写——预算分池实现时顺手建，规格点名防实现省略。
